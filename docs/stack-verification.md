## Механика и разрешение различий источников

- Решение смахивается влево и откладывается до завтра. Свайп вправо не подписывает. Подпись и размещение требуют второго нажатия. Последнее действие можно вернуть; состояние локально и сбрасывается при перезагрузке.
- В Figma вторичная кнопка исходной карточки — «Отложить». Это действие сохранено в интерфейсе.
- Перелистывание стопки добавлено по прямому требованию пользователя. Исходное дело, текст «Ждём Олега С.», действие «Напомнить» и три этапа сохранены по Figma.
- Для раскрытых состояний рисков переиспользованы существующие компоненты и токены. Их пиксельное соответствие Figma не заявляется: этих состояний нет в полученных узлах.
- Pointer-capture включается после определения горизонтального жеста. Вертикальная прокрутка сохраняется; отмена и потеря захвата возвращают карточку. Всплывающее событие потери неявного захвата от дочернего текста не отменяет передачу жеста обёртке.

## Проверки

- `npm run build` — успешно.
- `tsc -b --pretty false` и адресный ESLint изменённых компонентов/данных/тестов — успешно.
- `tests/stack-interactions.spec.ts`: 9 сценариев прошли в Chromium: оси и причины; touch-свайп/отмена/возврат; подпись в два касания; вертикальная прокрутка; пустая очередь; переключение дел и напоминания; геометрия/слои; мышь и обычная анимация; адаптация 320–430 px.
- Основной прогон использует reduced motion; отдельный сценарий включает обычную анимацию. События touch отправляются через Chromium CDP, мышь — через Playwright.
- Проверка production-сборки выполнена без дополнительного HTTP-сервера: `STACK_OFFLINE_PREVIEW=1`, маршруты `http://stack.test/**` отдают локальные файлы `dist`. Общая команда проекта для этих же тестов: `npx playwright test tests/stack-interactions.spec.ts --project=mobile-chromium`.
- Скриншоты реализации — `test-results/stack/`, начальная геометрия. При съёмке отдельной секции фиксированная нижняя навигация скрыта, масштаб PNG — CSS pixels.
- Физический мобильный экран и WebKit в рамках этой области не проверялись.

## Открытое визуальное ограничение общего слоя

Для плашки, обеих карточек, четырёх нижних полос и последней точки этапов через `use_figma` подтверждён **нативный GLASS**: radius 49, refraction 0.7, depth 40, lightAngle 158, lightIntensity 1, dispersion 0.5, splay 0.49. Дополнительно: INNER_SHADOW `(0,-2), radius8, white/.3`; DROP_SHADOW `(0,0), radius1.6, #e8e8eb` с `showShadowBehindNode=false`; `(0,1), radius6, #030306/.04` и `(0,6), radius16, white/.06` с `showShadowBehindNode=true`.

Существующий общий `.fx-glass` содержит CSS-градиент и тени, но не воспроизводит перечисленные оптические параметры GLASS. Он оставлен без новой упрощённой замены; общий `ui.css` принадлежит C. Параметры и ограничение переданы C. **Полное соответствие эффектов Figma не подтверждено.** Это не устраняется успешной проверкой геометрии и жестов.
